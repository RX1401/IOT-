# IOT posture detection system
This system is designed to monitor and correct a user's posture in real-time using an MPU6050 accelerometer and gyroscope sensor. It detects body orientation and identifies poor posture based on predefined thresholds. When incorrect posture is detected:

A buzzer sounds an alert to notify the user.

An LED lights up as a visual indication.

Posture data is transmitted wirelessly to a smartphone or other device via a Bluetooth module (e.g., HC-05) for further monitoring or logging.

The system is compact and wearable, ideal for students or professionals who sit for long hours, promoting healthier habits through real-time feedback.
